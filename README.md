# DS-with-Python
Includes: List, Tuple, Set, Linked list, Stack, Queue, Graph, Heap, Recursion and Tree

The case scenario used is that a user will input some data and choose the DS in which the data must be recieved in the output.

Step 1: Import the libraries and functions which are required. 

Step 2: Write the blueprint of certain DS (like Linked List or Tree) since without them we won't have a template to work on. 

Step 3: Take the raw input of data from the user. 

Step 4: Have a menu for the user from which the desired DS can be chosen. 

Step 5: The raw input must be parsed (converted to int if possible or float). 

Step 6: The parsed data must be used to demonstrate the DS chosen by the user. For this, elif or match structure can be used (elif used in this code). 

Step 7: When the user inputs the name of prefered DS, the data will be illustrated in so. Every DS mentioned in the menu must have a elif or match case refering to it.
